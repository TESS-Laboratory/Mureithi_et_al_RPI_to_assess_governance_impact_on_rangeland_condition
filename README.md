# Mureithi_RPI_Rangeland_Governance_Comparison

This repository contains the code used to reproduce the analyses, figures and tables presented in:

Mureithi, I.N., et al. (2026). Relative Productivity Index reveals contrasting rangeland condition trajectories across governance types in southern Kenya. *African Journal of Range and Forage Science* (in review).

A permanent version of this repository is archived at (https://zenodo.org/records/22017493)

Contact Isaac Nduta Mureithi at [I.N.Mureithi@exeter.ac.uk]

---

### Project overview

This research investigates how spatial patterns and long-term trends in relative vegetation productivity (RPI) reveal variations in rangeland condition across governance regimes in the Amboseli-Tsavo ecosystem of southern Kenya. The repository integrates multi-decadal GPP satellite data with quantile regression forest modeling and non-parametric trend analysis across national parks, conservancies, group ranches, and settled areas. It provides the full computational workflow to reproduce all spatio-temporal performance assessments, Theil-Sen slope estimates, and comparative governance figures presented in the manuscript.

### Repository contents

The primary code and spatial data components included in this repository are listed below.

#### Scripts

| Script | Description |
| --- | --- |
| *scripts/RPI Manuscript.Rmd* | Main R Markdown document containing the complete analysis workflow including spatial data import, raster processing, metric calculation (MAE, RMSE, $R^2$), Theil-Sen slope estimation, and figure generation across governance zones. |

#### Data

| File | Description |
| --- | --- |
| *actual_gpp_ea_v2.tif* | Integrated annual GPP estimates for 22 hydrological years (Sept 2000–Aug 2023) based on the PML_V2 dataset. |
| *potential_gpp_ea_v2.tif* | Estimated potential GPP for each grid cell derived from a quantile regression forest model (90th percentile). |
| *rpi_ea_v2.tif* | Relative Productivity Index raster layer defined as the ratio between actual and potential GPP. |
| *rpi_ea_temporal_performance.tif* | Three-band quality control raster reporting pixel-level MAE, RMSE, and $R^2$ model metrics. |
| *Amboseli_Conservation_Areas/* | Shapefiles for AET conservancies and community lands (*AET_Conservancies*, *AET_Other_Conserved_Areas*); sourced from Sustain East Africa Ltd. / Dr. Peter Tyrrell. |
| *Tsavo_Conservation_Areas/* | Shapefiles for ranches and settled areas (*RanchesTTWCA*, *SettledAreas*); sourced from Amos Chege Muthiuru (King’s College London). |
| *WDPA_Amboseli_Tsavo/* | National Park boundary shapefiles sourced from the World Database on Protected Areas (WDPA; UNEP-WCMC & IUCN, 2025). |
| *RPI Datasets (GuyLomax)* | Relative Productivity Index v2 product layers for East African rangelands (Lomax et al. 2026, *Rangelands* 48(4):114–129, doi:10.1016/j.rala.2026.06.001). Downloaded from https://doi.org/10.5281/zenodo.14843887. Generated by the cited study, not by this analysis. |
| *Country_Borders/* | Africa and Kenya administrative boundaries and Kenya terrestrial protected areas; supplied through the University of Exeter BIOM4051 (GIS in Ecology and Conservation) module. |

### Obtaining the data

Input data are not redistributed in this repository, either because of file size
or because they were provided by third parties. Place them in `data/` using the
structure below; the analysis then runs unchanged.

    data/
      RPI_v2/
      Country_Borders/
      WDPA_Amboseli_Tsavo/National Parks&Reserves/
      Amboseli_Conservation_Areas/
      Tsavo_Conservation_Areas/

**RPI v2 product layers** (`RPI_v2/`) — `actual_gpp_ea_v2.tif`,
`potential_gpp_ea_v2.tif`, `rpi_ea_v2.tif`, `rpi_ea_temporal_performance.tif`.
An external product generated by Lomax et al. (2026), *Rangelands* 48(4):114–129,
doi:10.1016/j.rala.2026.06.001, not by this analysis. Download from
https://doi.org/10.5281/zenodo.14843887

**Protected area boundaries** (`WDPA_Amboseli_Tsavo/`) — World Database on
Protected Areas, April 2025 release, UNEP-WCMC and IUCN. Download the individual
site records from https://www.protectedplanet.net and unzip without modification.
WDPA site IDs: Amboseli 758, Chyulu Hills 19563, Tsavo West 19564, Tsavo East 752,
Ngai Ndethia 2595, South Kitui 2590. Redistribution is restricted under the WDPA
terms of use, so these files are not included here.

**Amboseli conservancies and community lands** (`Amboseli_Conservation_Areas/`) —
`AET_Conservancies.shp`, `AET_Other_Conserved_Areas.shp`. Provided by Sustain East
Africa Ltd. (Dr Peter Tyrrell); available on request from the provider.

**Tsavo ranches and settled areas** (`Tsavo_Conservation_Areas/`) —
`RanchesTTWCA.shp`, `SettledAreas.shp`. Provided by Amos Chege Muthiuru
(King's College London); available on request from the provider.

**Administrative and protected area boundaries for Kenya** (`Country_Borders/`) —
supplied through the University of Exeter BIOM4051 (GIS in Ecology and
Conservation) module. Equivalent public data are available from GADM
(https://gadm.org) and Protected Planet.
