# Mureithi_RPI_Rangeland_Governance_Comparison

This repository contains the code used to reproduce the analyses, figures and tables presented in:

Mureithi, I.N., et al. (2026). Relative Productivity Index reveals contrasting rangeland condition trajectories across governance types in southern Kenya. *African Journal of Range and Forage Science* (in review).

A permanent version of this repository is archived at https://doi.org/10.5281/zenodo.17662206

### Project overview

This research investigates how spatial patterns and long-term trends in relative vegetation productivity (RPI) reveal variations in rangeland condition across governance regimes in the Amboseli-Tsavo ecosystem of southern Kenya. The repository takes the published Relative Productivity Index v2 product (Lomax et al. 2026) exactly as distributed and analyses it across national parks, conservancies, group ranches, and settled areas. It applies the product's own per-pixel R² layer as a quality-control filter, summarises mean RPI by governance zone, and estimates non-parametric (Theil-Sen) trends for every retained pixel. It provides the full computational workflow to reproduce the zonal summaries, Theil-Sen slope estimates, figures and tables presented in the manuscript.

The RPI product itself, including the model of potential productivity and its performance metrics, was generated by Lomax et al. (2026) and is not re-created here.

### Obtaining the data

Input data are not redistributed in this repository, either because of file size
or because they were provided by third parties. Place them in `data/` using the
structure below; the analysis then runs unchanged.

    data/
      RPI Datasets (GuyLomax)/
      Country_Borders/
      WDPA_Amboseli_Tsavo/National Parks&Reserves/
      Amboseli_Conservation_Areas/
      Tsavo_Conservation_Areas/

**RPI v2 product layers** (`RPI Datasets (GuyLomax)/`) - `actual_gpp_ea_v2.tif`,
`potential_gpp_ea_v2.tif`, `rpi_ea_v2.tif`, `rpi_ea_temporal_performance.tif`.
An external product generated by Lomax et al. (2026), *Rangelands* 48(4):114–129,
doi:10.1016/j.rala.2026.06.001, not by this analysis. Download from
https://doi.org/10.5281/zenodo.14843887

**Protected area boundaries** (`WDPA_Amboseli_Tsavo/National Parks&Reserves/`) - World
Database on Protected Areas, April 2025 release, UNEP-WCMC and IUCN. Download the
individual site records from https://www.protectedplanet.net and unzip without
modification into folders named `Amboseli-…`, `TsavoEast-…` and `TsavoWest-…`
followed by the name of the download (for example
`Amboseli-WDPA_WDOECM_Apr2025_Public_758_shp`).
WDPA site IDs: Amboseli 758, Tsavo East 752, Tsavo West 19564. Redistribution is
restricted under the WDPA terms of use, so these files are not included here.

**Amboseli conservancies and community lands** (`Amboseli_Conservation_Areas/`) -
`AET_Conservancies.shp`, `AET_Other_Conserved_Areas.shp`. Provided by Sustain East
Africa Ltd. (Dr Peter Tyrrell); available on request from the provider.

**Tsavo ranches and settled areas** (`Tsavo_Conservation_Areas/`) -
`RanchesTTWCA.shp`, `SettledAreas.shp`. Provided by Amos Chege Muthiuru
(King's College London); available on request from the provider.

**Kenya national and county boundaries** (`Country_Borders/GADM/`) - Database of
Global Administrative Areas (GADM), version 4.1, levels 0 and 1 (https://gadm.org;
free for academic and other non-commercial use). The script downloads these
through the `geodata` package the first time it runs (an internet connection is
needed once) and reuses the saved files afterwards. They are used for map context
and to define the extent of the Kenya-wide summaries.

**Kenya terrestrial protected areas for map context** (`Country_Borders/`) -
`kenya_terrestrial_protected_areas_wgs84.shp`, from the World Database on Protected
Areas (UNEP-WCMC and IUCN), used in Figure S1 only.

**Africa country outlines** (Figure 1A) - Natural Earth, 1:50m (public domain,
https://www.naturalearthdata.com), read through the `rnaturalearth` package. The data
are installed with the packages by `renv::restore()`, so nothing has to be downloaded.

**Photograph for Figure 1B** (`images/Figure_1B_elephants_Amboseli.jpg`) - the
photograph (an elephant browsing a tree in the savanna) is the only part of a figure that is not generated from data. If the
file is absent the script still runs and draws a labelled placeholder in panel B.
